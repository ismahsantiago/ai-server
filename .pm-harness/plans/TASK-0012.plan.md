## Risks
- Sharing provider integration trees can expose credentials, session material, or machine-local permission grants. Mitigation and rollback: repository-local deny rules, exact-index review, redacted scanning, and security-engineer approval are mandatory; a verified secret stops integration, requires revocation/rotation, and may require separately authorized history rewriting if already published.
- Sharing `.pm-harness/` can leak context or violate project isolation if reused elsewhere. Mitigation and rollback: document that this corpus belongs only to this repository/project, retain the same-project boundary in activation and handoff files, scan memory/state for sensitive operational content, and use governed append-only correction rather than deleting history.
- Excluding too much can make a clean clone unable to activate the team; including too much can import executables or nondeterministic dependencies. Mitigation and rollback: classify canonical sources versus generated pointers, use `agents check`, test an index-only tree and a no-local clone, and revert only the bounded portability commit if the committed clone cannot reproduce the contract.
- `.opencode/node_modules/` is approximately 61 MiB and contains executable symlinks; lock/package metadata may not be needed by the Markdown-only routers. Mitigation: never commit installed dependencies, prove the minimal OpenCode surface without them, and retain package metadata only if a documented executable runtime requirement is demonstrated and security-reviewed.
- Existing documentation conflicts on model placement and evidence terminology. Mitigation: reconcile all named operator documents in one task, treat `README.md`/current generator behavior as the executable contract, and block closure if a fresh reader can still infer that matrix/doctor output proves runtime readiness.
- Clean-checkout testing can accidentally depend on the dirty tree, global ignores, credentials, or host caches. Mitigation: stage an explicit allowlist, test with `git checkout-index`, repeat from `git clone --no-local`, inspect ignore provenance with `git check-ignore -v`, and require absence assertions before running gates.
- Full CI depends on Docker, Compose, ShellCheck, locked Python dependencies, and may create ignored artifacts. Mitigation: record prerequisite failures literally, use a disposable virtual environment and temporary checkout, remove only task-created temporary resources, and distinguish an environmental block from a passing product gate.
- A commit is reversible locally but publication changes the collaboration boundary. Mitigation and rollback: create no tag/release/push during worker execution; preserve the pre-change SHA; if a shared commit must be undone, use a normal revert commit rather than reset or force-push.
