## Objective
Extend the ai-server generator with model scenario test matrix and shorthand configuration mode so operators can generate validated launch workspaces for named lightweight-to-maximum models and their profile/access combinations using concise commands.

## Todos
- [x] Add model catalog schema and AC: repository stores model presets for Ornith 1.0 9B, Devstral Small v25.07, Qwen 3 Coder 7B, SmolLM 3 3B, and Phi-4 14B with capability tags and memory guidance.
- [x] Add shorthand config mode and AC: generator supports concise selectors (preset aliases) that expand into setup/profile/model/access options.
- [x] Add command shortcuts/scripts and AC: generated workspace includes one-command start/validate/smoke scripts and top-level helper command examples are documented.
- [x] Add scenario matrix tests and AC: automated tests cover each named model preset and core combinations (localhost medium, localhost medium-fast, LAN guarded failure without auth).
- [x] Add validation rules and AC: oversize/risky combinations produce explicit warnings or validation failures according to constraints.
- [x] Update docs/changelog and AC: roadmap/usage docs describe shorthand mode, scenario matrix, and test interpretation for go/no-go.

## Gates
- `python3 -m unittest`
- `python3 .pm-harness/bin/harness.py validate`
- `python3 .pm-harness/bin/harness.py plan check TASK-0004`
- `python3 .pm-harness/bin/harness.py changelog check --task TASK-0004`
- `test -f .pm-harness/HARNESS-SPEC.md`
- `python3 -m ai_server_generator list models`
- `python3 -m ai_server_generator matrix --preset ornith-9b --profile medium --access localhost`
- `python3 -m ai_server_generator generate --preset ornith-9b --profile medium --access localhost --out generated/ornith-medium-localhost --force`
- `python3 -m ai_server_generator validate generated/ornith-medium-localhost`
- `python3 -m ai_server_generator generate --preset phi-4-14b --profile good --access localhost --out generated/phi4-good-localhost --force`
- `python3 -m ai_server_generator generate --preset devstral-small-v25.07 --profile medium --access lan --out generated/devstral-lan-no-auth --dry-run` must exit non-zero

## Risks
- Model names and tags could drift from real upstream availability; mitigate by marking preset catalog as local lab presets with explicit version/date metadata.
- A shorthand mode can hide risky defaults; mitigate by always emitting expanded resolved configuration in generated manifest and runbook.
- Test matrix may become too large for fast feedback; mitigate with a minimal mandatory matrix plus optional extended matrix command.
- 14B profile generation may suggest unsupported runtime behavior on 12 GB RAM; mitigate by warning in matrix output and docs that generation != guaranteed runtime fit.
