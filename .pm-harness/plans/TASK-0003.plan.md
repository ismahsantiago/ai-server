## Risks
- Adding Jinja2 introduces a dependency; mitigate with a minimal `requirements.txt` and clear install/run instructions.
- Generated files could overwrite user changes; mitigate with default refusal when output exists and explicit `--force` only for generated paths.
- LAN generation could become unsafe; mitigate by failing LAN generation without bearer token and allowlist.
- Scope could grow into full RAG/Vision; mitigate by limiting TASK-0003 to chat-localhost-medium and validation skeleton.
- Existing root Sprint 1 files could conflict with generated outputs; mitigate by treating root files as compatibility examples and source material for templates.
